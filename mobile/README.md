# ArrendaJá Mobile

Aplicação móvel inicial construída com Expo e React Native.

## Executar
1. Instalar Node.js 20 ou superior.
2. Nesta pasta, executar `npm install`.
3. Executar `npm start`.
4. Abrir com Expo Go ou emulador compatível.

## Antes de publicar
Ainda é necessário implementar e testar autenticação, publicação de imóveis, favoritos, integração com a API, tratamento de erros, configuração de URL por ambiente, ícones e splash screen, identificadores Android/iOS, permissões, política de privacidade e builds assinados.

Esta aplicação é um ponto de partida e não deve ser considerada pronta para Google Play ou App Store.
