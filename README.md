# ArrendaJá — MVP

Portal imobiliário inicial para Angola. O projeto inclui website responsivo, API Express, SQLite, autenticação, publicação por proprietários diretos, pesquisa de imóveis, uploads de fotografias e pedidos de verificação.

## Preços iniciais
- Plano Destaque: 3.000 Kz
- Verificação Presencial: 6.500 Kz

## Estado
Este repositório está a ser preparado. O MVP não deve ser considerado pronto para produção: pagamentos reais, verificação documental, painel administrativo visual completo, segurança reforçada e publicação Android/iOS ainda exigem trabalho.

## Estrutura pretendida
- `server.js` — servidor/API
- `src/db.js` — base de dados SQLite
- `public/` — portal web
- `mobile/` — ponto de partida Expo/React Native
- `.env.example` — variáveis de ambiente
